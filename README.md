# Naninhas — custos e preços

Planilha interativa (arquivo único `index.html`) para calcular custo de matéria-prima, mão de obra, preço de venda e margem de peças artesanais (naninhas, dados, travesseiros, babeiros, toalhas de boca, kit touca).

Os dados ficam salvos no navegador (localStorage). Use **Backup → Exportar** para guardar um arquivo JSON e **Importar** em outro aparelho.
